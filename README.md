# Calendar Viewer

An interactive monthly calendar application.

## Features

- Month navigation
- Current date highlighting
- Today shortcut

## How to Use

Use the navigation buttons to explore different months.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Open the current month and locate today's date.
- [ ] Navigate to the previous and following months.
